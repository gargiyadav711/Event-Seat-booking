# Event Seat Booking Website

## Project Overview

The Event Seat Booking Website is a frontend web application that allows users to explore upcoming events, select seats, confirm bookings, and manage their bookings.

The website provides a simple and attractive interface where users can book seats for different events. Booking information is stored in the browser using Local Storage, so no backend or database is required.

## Features

- Responsive event booking interface
- Upcoming events section
- Event-wise seat selection
- Different seat categories
- Available, selected, and booked seat states
- Booking summary
- Automatic total price calculation
- My Bookings section
- Booking cancellation
- Event-specific seat storage
- Sign-up popup
- Animated circular event image section
- Local Storage support
- No backend required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Browser Local Storage
